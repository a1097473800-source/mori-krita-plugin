Mori 0.4.12 · Mac 测试版

适用于 macOS 12 或更新版本，支持 Apple 芯片与 Intel。新建或打开画布后显示 Mori 面板，顶部可切换「实时模式 / Mori 工作台」。账号、积分与生成历史共用 Mori 服务。

统一设置

点击面板右上角齿轮打开独立设置窗口，管理画布参考、实时与选区偏好、插件与网页更新。偏好自动保存，有新版本时齿轮显示提醒。设置中可手动检查 Mac 插件更新。

参考图默认使用「原图参考 · 无损」，保留原始尺寸。实时、工作台与选区共用参考图偏好；需要节省上传时间时可在设置中选择快速参考。生成结果按比例放入原画布位置，并作为独立图层保存。

实时模式

  1. 使用现有 Mori 邮箱账号登录，填写提示词，选择主体图层和可选参考图层。
  2. 选择模型、分辨率与质量，点击「立即生成」；或开启「自动生成」在停笔后提交。每轮有效生成使用账号积分。
  3. 在预览中查看结果，点击「放入 Krita 画布」，或启用自动放入。

同一时间只运行一个实时任务。切换页面或隐藏面板会暂停自动生成；切换账号、文档或输入后，旧结果不会自动回填。网络异常不会自动重发收费请求。

选区助手

建立选区后，在选区下方输入修改要求并点击「渲染」。可切换直接修改与智能体模式，默认比例跟随选区。结果新增到原文档的对应区域；可在统一设置中关闭选区栏。

Mori 工作台

  1. 切换到「Mori 工作台」，使用现有 Mori 邮箱账号登录。
  2. 在 Krita 选择区域或图层，点击「添加为参考」。
  3. 在 Mori 画布生成，或添加「Mori 创作家」开始对话。
  4. 开启生成后加入图层，结果会写入提交时的原文档与区域。

无打开文档时，结果创建新文档。已关闭的目标文档不会被替换成其他活动文档。云端画布与网站共用；同时编辑发生冲突时，先导出当前版本再刷新。

Mac 登录会话存入系统钥匙串，不保存密码。退出账号会清除已保存会话，会话失效或钥匙串不可用时可重新登录。Google 登录暂未接入，请使用邮箱账号。

安装与更新

完整 DMG 包含官方 Krita、Mori 和 AI Diffusion。保存作品并完全退出 Krita 后，运行「安装 Mori.app」。已有 Krita 可通过「工具 → 脚本 → 导入 Python 插件」导入 macOS-Plugin.zip，在 Python 插件管理器启用插件后重启。

安装器与 Mori 原生组件尚未经过 Apple Developer ID 签名与公证，首次打开说明见安装包内的「安装说明.txt」。AI Diffusion 后端和模型需单独配置；本包未包含 Vision Tools。
