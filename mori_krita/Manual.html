Mori 0.4.15 · 实时绘画与工作台

账号、积分与生成历史共用 Mori 服务器。欢迎页隐藏面板，新建或打开画布后显示；顶部可切换「实时模式 / Mori 工作台」。

布局与工作区

安装包加入卓尔谟及另外9个工作区，在工作区选择器中切换。窗口布局包含「Mori 工作台」。AI Image Generation面板可自由拖动和浮动，Mori不再将其强制还原。

实时模式

  1. 登录 Mori，填写提示词，选择主体图层和可选的多个参考图层。
  2. 选择模型、1K / 2K / 4K，以及模型支持的质量。默认 Banana 2.1、1K、停笔 2 秒（以服务器可用模型为准）。
  3. 点击「立即生成」，或开启「自动生成」在停笔后提交。自动开关默认关闭；开启后每一轮有效生成均使用账号积分。
  4. 在预览中查看结果，点击底部「放入 Krita 画布」，或勾选自动放入。结果作为独立新图层，原始像素保留，旧结果层隐藏。

一次最多一个实时任务，后续修改合并到下一轮；输入不变时跳过，不循环生成结果层。切换页面或隐藏面板会暂停自动生成；生成中切换账号、画布或修改输入时，旧结果不会自动回填。网络异常不自动重发收费请求。右上角「···」提供服务器、工作台自动回填、选区栏和更新设置。

选区下方直接修改

建立新选区后，提示词栏在选区下方自动展开；输入要求，点击「渲染」或 Ctrl+Enter。右上箭头或输入框中的 Esc 可折叠，草稿保留。左下参数菜单可切换「直接修改 / 智能体」，默认比例跟随选区。发送时才读取并上传选区，结果新增到原文档的对应区域。

右侧完整工作台可以收起；「选区栏」总开关位于其顶部。首次发送可直接通过邮箱账号登录。

连接与恢复

点击设置中的“连接与恢复”。页面空白时先点击“刷新页面”，仍未恢复时点击“重新连接”。“刷新画面”会重新绘制画布、面板并更新图层；“刷新账号”重新获取账号状态和积分。刷新不会提交生成任务。

完整工作台

切换到工作台时先播放居中的 Mori SVG 路径描画动画，页面准备完成后自动显示。加载动画没有说明文字；失败时显示原因并可重新加载。切回实时模式会同步隐藏浏览器窗口。

  1. 在停靠面板中打开「Mori 画布」。
  2. 选择「通过浏览器登录（支持 Google）」，或使用 Mori 邮箱密码登录。
  3. 在 Krita 选择区域或图层，点击「添加为参考」。
  4. 在 Mori 画布生成，或添加「Mori 创作家」开始对话。
  5. 开启「生成后加入图层」，生成结果会写入提交时的原文档与区域。

无打开文档时，结果创建新文档。已关闭的目标文档不会被替换成其他活动文档。

参考图默认使用「原图无损」，保留原始尺寸的无损像素；需要更快上传时，可手动切换「快速参考 · 2048」。处理在后台进行，上传显示实际进度。相同参考素材会复用，本机预览无需再次从服务器下载。

「导入到画布」默认自动识别：选区优先，其次当前有内容的图层，最后整个画布。图片直接显示在 Mori 画布并后台上传，完成后更新原节点。框选拖动期间浮栏隐藏，松手后再显示，以避免干扰绘画。

插件和网页使用同一服务器、同一账号的云端画布。空闲画布约4秒更新，列表约8秒更新；同时编辑出现版本冲突时，先导出当前版本再刷新。首次打开工作空间会将旧本地画布复制为带「Krita 导入」后缀的新画布，原文件保留；其中创作家节点开启新对话。密码不保存；登录会话通过 Windows 当前用户加密保护，下次启动验证后自动恢复。退出账号会清除保存的会话，服务器判定会话过期后需要重新登录。

0.3.0同步新版工作空间、多画布、创作记录、灵感库、审美风格与图片编辑。0.4.8起图结构与网站共享，旧本地画布迁移为云端副本。公共灵感可预览，原帖在默认浏览器打开；导出使用本机保存对话框。

当前预览版支持 Windows x64、带 Python 插件的 Krita 5.x 和 Microsoft Edge WebView2 Runtime。Google 用户可选择「通过浏览器登录（支持 Google）」，在系统浏览器中完成登录并确认连接，随后返回 Krita。浏览器授权完成后显示「授权成功」，点击该按钮不会跳转网站，请返回 Krita 继续创作。原有 Mori 邮箱密码登录仍可使用。
