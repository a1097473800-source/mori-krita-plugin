Mori 0.4.0 · 实时绘画与工作台

账号、积分与生成历史共用 Mori 服务器。欢迎页隐藏面板，新建或打开画布后显示；顶部可切换「实时模式 / Mori 工作台」。

实时模式

  1. 登录 Mori，填写提示词，选择主体图层和可选的多个参考图层。
  2. 选择模型、1K / 2K / 4K，以及模型支持的质量。默认 Banana 2.1、1K、停笔 2 秒（以服务器可用模型为准）。
  3. 点击「立即生成」，或开启「自动生成」在停笔后提交。自动开关默认关闭；开启后每一轮有效生成均使用账号积分。
  4. 在预览中查看结果，点击底部「放入 Krita 画布」，或勾选自动放入。结果作为独立新图层，原始像素保留，旧结果层隐藏。

一次最多一个实时任务，后续修改合并到下一轮；输入不变时跳过，不循环生成结果层。切换页面或隐藏面板会暂停自动生成；生成中切换账号、画布或修改输入时，旧结果不会自动回填。网络异常不自动重发收费请求。右上角「···」提供服务器、工作台自动回填、选区栏和更新设置。

选区下方直接修改

建立选区后输入要求，点击「渲染」或 Ctrl+Enter。右上箭头或输入框中的 Esc 可折叠，草稿保留。左下参数菜单可切换「直接修改 / 智能体」，默认比例跟随选区。发送时才读取并上传选区，结果新增到原文档的对应区域。

右侧完整工作台可以收起；「选区栏」总开关位于其顶部。首次发送可直接通过邮箱账号登录。

完整工作台

  1. 在停靠面板中打开「Mori 画布」。
  2. 使用现有 Mori 邮箱账号登录。
  3. 在 Krita 选择区域或图层，点击「添加为参考」。
  4. 在 Mori 画布生成，或添加「Mori 创作家」开始对话。
  5. 开启「生成后加入图层」，生成结果会写入提交时的原文档与区域。

无打开文档时，结果创建新文档。已关闭的目标文档不会被替换成其他活动文档。

参考图默认使用「快速参考 · 2048」，只缩小上传副本；需要原始尺寸与无损像素时切换「原图参考 · 无损」。处理在后台进行，上传显示实际进度。相同参考素材会复用，本机预览无需再次从服务器下载。

「导入到画布」默认自动识别：选区优先，其次当前有内容的图层，最后整个画布。图片直接显示在 Mori 画布并后台上传，完成后更新原节点。框选拖动期间浮栏隐藏，松手后再显示，以避免干扰绘画。

插件画布按账号保存在本机，网页画布单独保存。密码不保存；登录会话通过 Windows 当前用户加密保护，下次启动验证后自动恢复。退出账号会清除保存的会话，服务器判定会话过期后需要重新登录。

0.3.0同步新版工作空间、多画布、创作记录、灵感库、审美风格与图片编辑。原有插件画布作为默认画布保留；新建画布会登记服务器ID，图结构仍保存在本机。公共灵感可预览，原帖在默认浏览器打开；导出使用本机保存对话框。

当前预览版支持 Windows x64、带 Python 插件的 Krita 5.x 和 Microsoft Edge WebView2 Runtime。Google 登录暂未接入，使用现有邮箱账号。
